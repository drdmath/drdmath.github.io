Further Simplification of the Dirichlet GRH Argument

A parallel project · Work in progress

Overview

This is a parallel project exploring a further simplification of the approach to Dirichlet GRH. It is being developed alongside the main Human-Readable Proof Project, but is maintained as a separate line of work.

Status: work in progress. The current manuscript is incomplete and should not be read as a completed proof of Dirichlet GRH. The manuscript itself states that Dirichlet GRH remains the target conjecture.

Current Manuscript

Version 555 · 27 November 2026

Zeros of Dirichlet L-functions and One-Sided Estimates

Abstract. We construct the real determinant tests at every level of the triangular array. The ordinary arrow and the arrow between consecutive offsets have the same parameter insertion after reversing the order on the latter. This identifies all inserted weights and proves positivity of each source projection. Dirichlet GRH remains the target conjecture.
